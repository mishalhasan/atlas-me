# AtlasMe — Database Schema

**Database:** PostgreSQL
**ORM:** Sequelize
**Hosting:** Supabase (free tier)

---

## Models Overview

| Model | Table | Description |
|-------|-------|-------------|
| User | users | Registered AtlasMe accounts |
| Pin | pins | Travel pins dropped on the map |

**Relationship:** User has many Pins. Pin belongs to User.

---

## Model 1 — User

### Sequelize Definition

```javascript
// server/models/User.js
const { DataTypes } = require('sequelize')
const sequelize = require('../config/database')

const User = sequelize.define('User', {
  id: {
    type: DataTypes.INTEGER,
    primaryKey: true,
    autoIncrement: true,
  },
  email: {
    type: DataTypes.STRING,
    allowNull: false,
    unique: true,
    validate: {
      isEmail: true,
      notEmpty: true,
    },
  },
  username: {
    type: DataTypes.STRING,
    allowNull: false,
    unique: true,
    validate: {
      len: [3, 20],
      isAlphanumeric: true,
      notEmpty: true,
    },
  },
  password: {
    type: DataTypes.STRING,
    allowNull: false,
    validate: {
      len: [8, 255],
      notEmpty: true,
    },
  },
}, {
  tableName: 'users',
  timestamps: true,           // adds createdAt and updatedAt automatically
  underscored: true,          // snake_case column names in DB
})

module.exports = User
```

### Fields

| Field | Type | Required | Unique | Notes |
|-------|------|----------|--------|-------|
| id | INTEGER | auto | yes | Primary key, auto-increment |
| email | STRING | yes | yes | Valid email format enforced |
| username | STRING | yes | yes | 3-20 chars, alphanumeric only |
| password | STRING | yes | no | Stored as bcrypt hash |
| created_at | TIMESTAMP | auto | no | Auto-generated by Sequelize |
| updated_at | TIMESTAMP | auto | no | Auto-updated by Sequelize |

### Validation Rules
- `email` — must be valid email format, not empty, unique
- `username` — 3-20 characters, alphanumeric only, not empty, unique
- `password` — minimum 8 characters (store hash, never plaintext)

### Security Notes
- Never return `password` field in API responses
- Hash password with bcrypt (10+ salt rounds) before saving
- Use Sequelize hooks to hash automatically:

```javascript
User.beforeCreate(async (user) => {
  user.password = await bcrypt.hash(user.password, 10)
})
```

## Model 2 — Pin

### Sequelize Definition

```javascript
// server/models/Pin.js
const { DataTypes } = require('sequelize')
const sequelize = require('../config/database')

const Pin = sequelize.define('Pin', {
  id: {
    type: DataTypes.INTEGER,
    primaryKey: true,
    autoIncrement: true,
  },
  userId: {
    type: DataTypes.INTEGER,
    allowNull: false,
    references: {
      model: 'users',
      key: 'id',
    },
    onDelete: 'CASCADE',
  },
  name: {
    type: DataTypes.STRING,
    allowNull: false,
    validate: {
      notEmpty: true,
      len: [1, 255],
    },
  },
  latitude: {
    type: DataTypes.FLOAT,
    allowNull: false,
    validate: {
      min: -90,
      max: 90,
    },
  },
  longitude: {
    type: DataTypes.FLOAT,
    allowNull: false,
    validate: {
      min: -180,
      max: 180,
    },
  },
  type: {
    type: DataTypes.ENUM('visited', 'wishlist'),
    allowNull: false,
    validate: {
      isIn: [['visited', 'wishlist']],
    },
  },
  countryCode: {
    type: DataTypes.STRING(2),
    allowNull: false,
    validate: {
      notEmpty: true,
      len: [2, 2],
      isUppercase: true,
    },
  },
  continent: {
    type: DataTypes.STRING,
    allowNull: false,
    validate: {
      notEmpty: true,
      isIn: [[
        'Africa',
        'Antarctica',
        'Asia',
        'Europe',
        'North America',
        'Oceania',
        'South America',
      ]],
    },
  },
  region: {
    type: DataTypes.STRING,
    allowNull: false,
    validate: {
      notEmpty: true,
    },
  },
}, {
  tableName: 'pins',
  timestamps: true,
  underscored: true,
})

module.exports = Pin
```

### Fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| id | INTEGER | auto | Primary key, auto-increment |
| user_id | INTEGER | yes | FK → users.id, cascades on delete |
| name | STRING | yes | Place name e.g. "Paris", "Tokyo" |
| latitude | FLOAT | yes | -90 to 90 |
| longitude | FLOAT | yes | -180 to 180 |
| type | ENUM | yes | 'visited' or 'wishlist' only |
| country_code | STRING(2) | yes | ISO 3166-1 alpha-2 e.g. 'FR', 'JP' |
| continent | STRING | yes | Derived from Mapbox or lookup table |
| region | STRING | yes | From Mapbox Geocoding response |
| created_at | TIMESTAMP | auto | Auto-generated |
| updated_at | TIMESTAMP | auto | Auto-updated |

### Validation Rules
- `latitude` — must be between -90 and 90
- `longitude` — must be between -180 and 180
- `type` — must be exactly 'visited' or 'wishlist'
- `continent` — must be one of the 7 valid continents
- `name`, `country`, `region` — not empty, max 255 chars
- `user_id` — must reference a valid existing user

## Associations

```javascript
// server/models/index.js
const User = require('./User')
const Pin = require('./Pin')

// One user has many pins
User.hasMany(Pin, {
  foreignKey: 'userId',
  as: 'pins',
  onDelete: 'CASCADE',
})

// Each pin belongs to one user
Pin.belongsTo(User, {
  foreignKey: 'userId',
  as: 'user',
})

module.exports = { User, Pin }
```

## Database Connection + Sync

```javascript
// server/server.js
const sequelize = require('./config/database')
const { User, Pin } = require('./models')

const connectDB = async () => {
  try {
    await sequelize.authenticate()
    console.log('PostgreSQL connected via Sequelize')
    await sequelize.sync({ alter: true })  // alter: true updates tables safely
    console.log('Models synced')
  } catch (error) {
    console.error('Database connection failed:', error)
    process.exit(1)
  }
}

connectDB()
```

> **Note:** Use `sync({ alter: true })` in development.
> In production, use migrations instead of sync.

## Derived Stats Queries

These run on the backend — not computed on the frontend.

### Top Region
```javascript
const topRegion = await Pin.findOne({
  attributes: [
    'region',
    [sequelize.fn('COUNT', sequelize.col('region')), 'count']
  ],
  where: { userId, type: 'visited' },
  group: ['region'],
  order: [[sequelize.literal('count'), 'DESC']],
  limit: 1,
})
```

### Countries Visited (unique count)
```javascript
const countries = await Pin.findAll({
  attributes: [[sequelize.fn('DISTINCT', sequelize.col('country_code')), 'country_code']],
  where: { userId, type: 'visited' },
})
const countriesCount = countries.length
```

### Continents Visited (unique count)
```javascript
const continents = await Pin.findAll({
  attributes: [[sequelize.fn('DISTINCT', sequelize.col('continent')), 'continent']],
  where: { userId, type: 'visited' },
})
const continentsCount = continents.length
```

### % of World
```javascript
const worldPercent = ((countriesCount / 195) * 100).toFixed(1)
```

## Mapbox Geocoding → Pin Fields

When a user searches and selects a location, the Mapbox Geocoding API returns:

```javascript
// Example Mapbox feature response
{
  place_name: "Paris, France",
  center: [2.3522, 48.8566],   // [longitude, latitude]
  context: [
    { id: "region...", text: "Île-de-France" },
    { id: "country...", text: "France" },
  ]
}
```

Map to pin fields like this:

```javascript
const countryContext = feature.context.find(c => c.id.includes('country'))

const pin = {
  name: feature.place_name,
  longitude: feature.center[0],
  latitude: feature.center[1],
  countryCode: countryContext?.short_code?.toUpperCase(), // e.g. 'FR'
  region: feature.context.find(c => c.id.includes('region'))?.text
           || feature.place_name,
  continent: getContinentFromISO(countryContext?.short_code), // ISO lookup
  type: 'visited', // or 'wishlist'
}
```

> **Note on continent:** Mapbox does not return continent directly.
> Use ISO country code to derive continent at pin creation time.
>
> **Recommended:** `i18n-iso-countries` or `countries-and-timezones` npm packages
> already have ISO → continent mappings built in. No manual lookup table needed.
>
> ```javascript
> // Example using countries-and-timezones
> const ct = require('countries-and-timezones')
> const country = ct.getCountry('FR')
> // → { name: 'France', continent: 'EU' }
> ```
>
> Continent is derived once at save time and stored — never re-derived on queries.
